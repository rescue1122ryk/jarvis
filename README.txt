JARVIS APK BANANE KE QADAM (GitHub par, free)

1) github.com par account banayen -> "New repository" -> naam: jarvis -> Create.
2) Is zip ko extract karein. Repository page par "uploading an existing file" dabayen
   aur extract hone wale folder ke ANDAR ki sari files/folders drag-drop karein
   (".github" folder samet). Neeche "Commit changes" dabayen.
   Agar ".github" upload na ho: Actions tab -> "set up a workflow yourself" ->
   build.yml ka text paste karein -> Commit.
3) Actions tab mein "Build APK" chalega (4-6 minute). Green tick aane par us par click
   -> neeche "Artifacts" mein "Jarvis-APK" download karein -> zip kholein -> app-debug.apk.
4) APK ko phone mein install karein (Unknown sources allow karna paray ga).
5) App kholein -> Contacts/Call/SMS ki ijazat dein.
6) WhatsApp auto-send ke liye: "Ikhsesibiliti on karein" button -> Installed apps -> Jarvis -> On.
   Agar On nahi hota (grey): Settings -> Apps -> Jarvis -> upar teen nuqtay -> "Allow restricted settings".
7) AI ke liye: Settings button -> OpenRouter key aur model likhein (model ka naam :free par khatam ho).
8) Net ke baghair Urdu bolna: Google app -> Settings -> Voice -> Offline speech recognition -> Urdu download.
