JARVIS v2 - GitHub se APK banane ke qadam
1) Purani repository mein files replace karein: is zip ki sari files upload karein (same naam wali files overwrite ho jayengi). Commit changes.
2) Actions tab -> sab se upar wali run -> sab se neeche Artifacts -> Jarvis-APK -> download -> app-debug.apk install.
   (Purani Jarvis app par hi install karein, update ho jayegi.)

VIVO Y100 SETTINGS (ek baar)
a) Restricted settings: Settings -> Apps -> Jarvis -> upar teen nuqtay -> Allow restricted settings.
   (Pehle ek baar Accessibility mein Jarvis on karne ki koshish karein, tab ye option aata hai.)
b) Accessibility -> Jarvis -> On.
c) App ke andar button 2: "Display over other apps" -> Jarvis -> Allow.
   Vivo mein: Settings -> Apps -> Jarvis -> Permissions -> "Background pop-ups"/"Display pop-ups while running in background" -> Allow.
d) Battery: Settings -> Battery -> Background power consumption management -> Jarvis -> "Allow high background power consumption".
e) i Manager -> App manager -> Autostart -> Jarvis On.
f) Recents mein Jarvis ko lock karein (app card neeche kheinch kar ya lock icon).
g) Net ke baghair: Google app -> Settings -> Voice -> Offline speech recognition -> Urdu download.

AI KEY KAHAN LAGAYEN: app ke andar "Settings (AI key)" button -> upar wale dabbe mein OpenRouter key paste -> Model mein openrouter/free rehne dein -> Save.
